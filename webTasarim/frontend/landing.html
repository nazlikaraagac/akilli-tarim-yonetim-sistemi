TARIM

Sistem Mimarisi

Sahadan sunucuya,
kesintisiz veri akışı.

Dört katmanlı mimari: IoT donanımından Flask backend'e, oradan web paneline ve mobil uygulamaya uzanan tam entegre bir tarım yönetim altyapısı.

01
IoT Sensör Altyapısı
Tarla ortamına yerleştirilen DHT22, kapasitif toprak nemi ve NPK sensörleri, MQTT protokolü üzerinden gerçek zamanlı veri akışı sağlar. Bağlantı koptuğunda veriler cihaz üzerinde tamponlanır, bağlantı geri geldiğinde sırasıyla iletilir.
MQTT / QoS-1 ESP32 DHT22 · NPK · Toprak Nemi Offline Buffer
02
Yapay Zeka Karar Destek Modülü
Scikit-learn Decision Tree modeli, sıcaklık, nem ve NPK verilerini birleştirerek sulama ihtiyacını tahmin eder. Bitki büyüme evresine özgü eşik değerleriyle gübre tavsiyesi üretir. Anomali tespiti sayesinde arızalı sensör verisi modele ulaşmadan elenir.
Scikit-learn Decision Tree NPK Analizi Anomali Tespiti
03
Web Yönetici Paneli
Ziraat mühendisleri ve sistem yöneticileri için Flask REST API üzerine inşa edilmiş HTML/JS arayüzü. Anlık sensör grafikleri, alarm yönetimi, tarım takvimi ve kullanıcı işlemleri tek ekranda. Karanlık mod ve Türkçe/İngilizce dil desteği ile gelir.
Flask · MySQL Chart.js REST API Docker
04
Çiftçi Mobil Uygulaması
React Native (Expo) ile geliştirilen çiftçi uygulaması, sahada tarlalar arası anlık durum takibi, sulama motoru tetikleme ve gübre onayı gibi kritik aksiyonları tek dokunuşla sunar. Backend erişilemez olsa dahi demo verileriyle çalışmaya devam eder.
React Native Expo iOS · Android Offline Fallback
